# Reflection

Draft answers to review so they match my experience.

## What did this project help you understand?

I better understand how interfaces, implementations, and tests work together.
Separating the layers makes a component easier to reuse and maintain.

## What was difficult?

Copying and transferring were easy to confuse. Comparing their behavior in the
tests helped explain why copying preserves the source while transferring clears it.

## Did your interest in software development change?

Seeing the component used in two different programs made the work more
interesting. It showed how a small library can support different needs.

## What skills did you practice?

I practiced Java interfaces, inheritance, testing, and Git. I also worked on
organizing files and explaining design choices clearly.

## How could you describe these skills on a resume?

- Worked with a layered Java component and JUnit tests.
- Documented method contracts and demonstrated two different uses.

## What do you want to learn next?

I want to compare different data structures behind the same interface and see
how they affect performance.

## What is your next step, and who could help?

I would write another client program and review the component's contracts.
A classmate or instructor could give feedback on the design and tests.
